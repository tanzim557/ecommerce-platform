A high-performance, full-featured modern e-commerce storefront web application. Built with React and Tailwind CSS, featuring multi-role workflows for customers, sellers, and platform administrators.

---

## Key Features

- Dynamic Storefront and Cart: Product filtering, real-time cart state management, quantity modifications, and instant price tallying.
- Customer Account Modal: Dedicated CustomerAccountModal for order tracking, profile management, and saved addresses.
- Merchant and Seller Hub: SellerModal empowering vendors to list new products, manage stock counts, and monitor sales.
- Integrated Admin Portal: AdminPanelModal offering comprehensive dashboard metrics, user controls, and order moderation.
- Polished Aesthetic UI: Clean glassmorphism styling, responsive layouts, and smooth interactions across devices.

---

## Tech Stack

- Framework: React 18
- Tooling and Bundler: Vite
- Styling: Tailwind CSS, PostCSS
- Iconography: Lucide React

---

## Getting Started

```bash
# Clone the repository
git clone https://github.com/tanzim557/ecommerce-platform.git
cd ecommerce-platform

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit http://localhost:5173 to explore the storefront.
